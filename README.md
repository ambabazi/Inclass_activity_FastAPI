# In-Class Activity: FastAPI Prediction API

This project takes a trained Decision Tree model (built on the California Housing dataset) and serves predictions through a simple FastAPI app.

## What's in this repo

- `main.py` — the FastAPI application with the `/predict` endpoint
- `treemodel.pkl` — the trained Decision Tree model (saved with pickle)
- `x_test.csv` — sample input data used to test predictions

## How it works

The app loads `treemodel.pkl` once when it starts. When you hit the `/predict` endpoint, it reads a row from `x_test.csv` and returns the model's prediction for that row.

## Setup

1. Clone this repo:
```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
```

2. Create and activate a virtual environment:
```bash
python3 -m venv venv
source venv/bin/activate
```

3. Install the required packages:
```bash
pip install fastapi uvicorn pandas numpy scikit-learn
```

## Running the app

```bash
uvicorn main:app --reload
```

The server will start at `http://127.0.0.1:8000`.

## Testing it

- Visit `http://127.0.0.1:8000/docs` for an interactive tester (auto-generated by FastAPI).
- Or go straight to `http://127.0.0.1:8000/predict` to get a prediction from the first row of test data.
- Add a `row` number to test a different row, e.g. `http://127.0.0.1:8000/predict?row=5`.

## Endpoints

| Endpoint   | Method | Description                                  |
|------------|--------|-----------------------------------------------|
| `/`        | GET    | Health check message                          |
| `/predict` | GET    | Returns a prediction; optional `row` param    |
